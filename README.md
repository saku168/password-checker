# Password Checker

A browser-only password criteria checker made with **HTML, CSS and vanilla JavaScript**.

## Features
- Checks password length.
- Checks for uppercase and lowercase letters.
- Checks for numbers and symbols.
- Displays feedback based on the criteria.

## Privacy
The password is evaluated locally in the browser by this project. It is not stored or transmitted by the app.

This is an educational checker, not a guarantee that a password is secure. Never enter a real password into a demo website or share it with anyone.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — checker interface
- `style.css` — styling
- `script.js` — criteria checks

## What this project practises
String checks, conditional logic, and updating feedback in the page.
